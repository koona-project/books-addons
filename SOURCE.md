# Where these folders come from

`examples/`, `starters/`, `skill/`, `schema/` and `withdrawn.json` are synced from Koona Books at commit `022d8065` (2026-11-21), except `examples/wikidata/` and `skill/koona-books-addons/examples/wikidata/`, which are from commit `68c3665d` (2026-11-24). Edit them in Koona Books and run `bun run addons:docs --sync`.
